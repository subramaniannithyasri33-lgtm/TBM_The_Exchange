## Problem Statement

Can you create a tiny ecosystem that survives on its own, or will everything eventually die? Build a small simulation containing grass, herbivores, and predators living together in a shared environment. Grass grows naturally, herbivores move around eating grass, and predators hunt herbivores for food. Every creature needs energy to survive, and animals can reproduce when they have enough food. Users should be able to adjust settings such as the starting populations, grass growth rate, and reproduction speed using sliders or controls. For example, adding too many predators might wipe out the herbivores, leaving the predators without food. Too many herbivores might consume all the grass and starve. The goal is to create a living ecosystem where populations constantly change, and players can experiment to discover what keeps the environment balanced.
